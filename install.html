Fillvisa OS

Open-source immigration forms you can inspect, fork, and self-host

Fillvisa OS is the open-source edition of Fillvisa's browser-based form tools. It is a frontend-only project built with HTML, CSS, JavaScript, local assets, and form pages.

Download latest source ZIP View on GitHub

The ZIP points to the main branch snapshot at download time. Downloaded copies do not auto-update.

Static by design

No package registry, app store, or backend install.

  • Frontend HTML, CSS, JavaScript, PDFs, and local libraries.
  • Clone, fork, download, inspect, and self-host.
  • Designed for online/static hosting in v1.
Install

How to install or self-host Fillvisa OS

For v1, Fillvisa OS is meant to run as an online static website. You can download the source, upload it to a static host, and serve it over the internet.

Step 1

Download

Use the GitHub ZIP link or clone the repository if you are comfortable with Git.

Step 2

Unzip

Keep the folder structure intact so pages can find their local CSS, JavaScript, PDFs, and assets.

Step 3

Host

Upload the files to GitHub Pages, Cloudflare Pages, Netlify, a static server, or your own website.

Step 4

Update

Download the latest main branch ZIP again or pull the newest commits when forms or editions change.

Internet required: Fillvisa OS can be self-hosted, but v1 is not packaged as an offline installer. Users should access it through an online or locally hosted web address, not as a guaranteed double-click offline app.
Editions

Open source, Fillvisa.com, and Plus are different surfaces

The same mission, three different ways to use it.

Fillvisa OS

The public AGPL source project. It is for transparency, forks, self-hosting, audits, and community contributions around supported free forms.

Open GitHub

Fillvisa.com

The hosted free version. It is the easiest place for users to fill supported public forms, use local browser storage, and download completed PDFs.

Browse free forms

Fillvisa Plus

The cloud workspace for individuals and professionals who need saved cases, multi-device access, collaborators, and broader family and employment-based workflows.

License

AGPL for the open-source core

Fillvisa OS is intended to use the GNU Affero General Public License, version 3. The goal is simple: people can use, study, modify, and self-host the code, while public hosted modifications should keep the same source-sharing spirit.

The license covers the open-source project code. Fillvisa trademarks, logos, and brand identity are separate and are not automatically licensed for reuse.

Plain-English summary

  • You can inspect, fork, and self-host Fillvisa OS.
  • If you modify and offer it over a network, share the corresponding source.
  • Keep third-party library notices and licenses intact.
  • Do not imply your fork is the official Fillvisa service unless you have permission.
