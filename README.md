## Features

- Free & open-source.
- Browser-based U.S. immigration form workflows.
- DS-160 support for nonimmigrant visa applications.
- DS-160 bookmarklet that helps autofill the official CEAC website.
- Family-based immigration form workflows.
- USCIS official PDF output for supported PDF-based forms.
- Ready-to-review completed PDFs.
- Self-hostable static frontend.
- No backend required for the open-source core.
- Form-specific validation and guidance.
- Public source code for transparency and auditability.
- Forkable and customizable for community use.
- AGPL-licensed open-source core.


## Supported forms include:

- DS-160: Nonimmigrant Visa Application
- AR-11: Alien’s Change of Address Card.
- G-1145: E-Notification of Application/Petition Acceptance.
- I-90: Green Card Renewal/Replacement Package.
- I-129-F: K-1 Visa Petition Package.
- I-130: Immigrant Visa Petition Package.
- I-130-A: Supplemental Information for Spouse Beneficiary.
- I-131: Travel Document Package.
- I-131-A: Carrier Documentation Package.
- I-134: Nonimmigrant Support Package.
- I-485: Adjustment of Status Package.
- I-751: Removal of Conditions Petition Package.
- I-765: Employment Authorization Package.
- I-821-D: DACA Application Package.
- I-864: Affidavit of Support Package.
- I-864-A: Contract Between Sponsor and Household Member.
- N-400: Naturalization Package.
- N-565: Citizenship Document Replacement Package.

## Fillvisa.com

The app hosted at [fillvisa.com](https://fillvisa.com) is the official hosted version of Fillvisa OS. It provides a simple browser-based way to complete supported U.S. immigration forms and download ready-to-review official PDF outputs.

The hosted app features:

- Browser-based form workflows.
- Local-first support for free forms, with progress saved in the browser.
- Single-player mode only.
- DS-160 support for nonimmigrant visa applications.
- DS-160 bookmarklet to help autofill the official CEAC website.
- Family-based immigration form workflows.
- USCIS official PDF output for supported PDF-based forms.
- No offline mode in the open-source version.
- No account required for supported free forms.
- Fillvisa Plus upgrade path for cloud sync, collaborators, and additional workflows.

## Quick start

**Note:** Fillvisa OS is not an npm package. It is a frontend-only static project. All required HTML, CSS, JavaScript, assets, and local libraries are included in the release ZIP.


Download the latest release from GitHub:

```bash
https://github.com/athos2113/fillvisa-os/releases


Then:
1. Download the latest Fillvisa OS ZIP release.
2. Unzip the file.
3. Open index.html in your browser.

No npm install, yarn, build step, backend, or package registry is required.
If your browser blocks a feature when opening files directly, serve the folder with any static web server or use the hosted version at fillvisa.com.

```
